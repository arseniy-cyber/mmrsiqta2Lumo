ВЕРСИЯ 12.0 (демонстрация)

КАК ПОСМОТРЕТЬ
1. Распакуйте ZIP.
2. Откройте index.html в браузере.
3. Для публикации на GitHub Pages загрузите содержимое папки сайта
   в корень репозитория: index.html, style.css, script.js,
   gallery-data.js, папку assets.

ВАЖНО: ФОРМА ПОКА НЕ ОТПРАВЛЯЕТ ЗАЯВКИ
При заполнении открывается только предпросмотр. Данные не передаются
мастеру и не сохраняются. Для настоящих заявок потребуется Telegram-бот
и защищённый Cloudflare Worker. Не публикуйте токен бота в HTML/JS.
Перед сбором настоящих персональных данных требуется корректно оформить
информирование и согласие на обработку персональных данных, а также
разработать защиту от спама, проверку размера и формата файлов.

=== Версия 20: подключение формы к Cloudflare ===
Форма из index.html отправляет данные на Worker по адресу, заданному в
script.js (BOOKING_ENDPOINT). Токен и CHAT_ID остаются только в Cloudflare
(Secrets). Заявки приходят в Telegram тестовому получателю.

Проверка: обнови ВЕСЬ комплект файлов на GitHub Pages и отправь заявку
с тестовыми данными, добавив 1 JPG. После ответа Telegram придёт сообщение
и фотография. Потом в Cloudflare замени CHAT_ID на ID Алины.
